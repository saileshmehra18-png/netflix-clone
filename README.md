# Netflix UI Clone

A frontend practice project recreating parts of the Netflix browsing interface using HTML and CSS.

## Project contents

- `netflix.html` — page structure
- `styles/` — styling
- `icons/` — interface icons
- `thumbnails/` — image assets

## Run locally

Clone the repository and open `netflix.html` in a browser.

## Purpose

This project was built to practise page layout, styling, asset organisation and recreating a familiar streaming-service interface.

> This is an educational frontend project and is not affiliated with Netflix.
